## РАЗДЕЛ 0 — АРХИТЕКТУРА (важно прочитать первым)

Сайт на **PHP** со сквозными подключаемыми частями.

```
inc/config.php   ← ВСЕ контакты, телефоны, адрес, часы, ID аналитики
inc/head.php     ← <head> + шапка + меню (метатеги у страниц свои!)
inc/footer.php   ← футер + куки-баннер + панель звонка + скрипты
*.php            ← 72 страницы, каждая задаёт свои $page_title/$page_desc
css/ js/ img/    ← статика
.htaccess        ← HTTPS, редиректы, кэш, сжатие, защита inc/
```

**Требования сервера:** PHP 7.4+, mod_rewrite. Есть на любом обычном хостинге.

**Как править сквозные элементы:** контакты — в `inc/config.php`, шапка —
в `inc/head.php`, футер — в `inc/footer.php`. Меняется на всём сайте разом.
Подробно — в файле `PHP-как-редактировать.md`.

**НЕ заливать на хостинг:** `*.py`, `*.md` (утилиты и документация).
Заливать: все `.php`, `inc/`, `css/`, `js/`, `img/`, `.htaccess`,
`robots.txt`, `sitemap.xml`, `llms.txt`.

**Проверка PHP:** если страница скачивается вместо открытия — PHP не включён
на хостинге, обратитесь в поддержку. Локально через браузер файлы не откроются
(нужен PHP-сервер): для проверки — `php -S localhost:8000` в папке сайта.

## РАЗДЕЛ 2 — SSL И ДОМЕН (обязательно)

- [ ] **2.1** Подключить SSL-сертификат (Let's Encrypt бесплатный)
- [ ] **2.2** Настроить редирект **HTTP → HTTPS** (301)
- [ ] **2.3** Выбрать канонический вид домена — с www или без — и настроить
      301-редирект со второго варианта на выбранный.
      **Важно:** в коде везде указано `https://a-global.by/` (без www).
      Значит, редиректить `www.a-global.by → a-global.by`.
      Если решите наоборот (с www) — нужно поменять все canonical и sitemap.
- [ ] **2.4** Проверить, что `https://a-global.by` открывается без ошибок сертификата

### Пример .htaccess (Apache)
```apache
RewriteEngine On
# HTTP → HTTPS
RewriteCond %{HTTPS} off
RewriteRule ^(.*)$ https://%{HTTP_HOST}/$1 [R=301,L]
# www → без www
RewriteCond %{HTTP_HOST} ^www\.a-global\.by [NC]
RewriteRule ^(.*)$ https://a-global.by/$1 [R=301,L]
```

### Пример nginx
```nginx
server {
    listen 80;
    server_name a-global.by www.a-global.by;
    return 301 https://a-global.by$request_uri;
}
server {
    listen 443 ssl;
    server_name www.a-global.by;
    return 301 https://a-global.by$request_uri;
}
```

      **Не блокируйте их** на уровне сервера/файрвола/Cloudflare!
- [ ] **6.3** Если стоит Cloudflare — проверить, что в настройках не включена

      логику подбора) — это то, что ИИ-поиск цитирует. Уже сделано

### Почему это важно
Всё больше B2B-клиентов ищут поставщиков через ChatGPT и Perplexity
(«где купить бентонит для ГНБ в Беларуси»). Файл llms.txt и разрешённые
ИИ-боты дают шанс попасть в такие ответы. Если заблокировать ботов —
сайт станет невидим для этого канала.
