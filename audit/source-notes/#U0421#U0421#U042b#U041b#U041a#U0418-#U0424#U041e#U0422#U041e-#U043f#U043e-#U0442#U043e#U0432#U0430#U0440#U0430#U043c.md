# Ссылки на примеры фото по каждому товару — ANKO GLOBAL

Для каждого товара из каталога — ссылка, где можно **посмотреть, как он выглядит**.

Два типа ссылок:
- **Производитель / магазин** — прямая ссылка на страницу с реальным фото товара.
  Самый точный вариант. Как дилер, вы можете запросить эти фото официально.
- **Поиск на стоке** — ссылка на поиск с уже вписанным запросом (для типовых
  позиций, у которых нет конкретного бренда — инструмент, трубы).

**Важно про права:** ссылки ниже — чтобы ПОСМОТРЕТЬ пример. Просто скачать фото
с сайта производителя и поставить к себе — нельзя (это их собственность).
Правильный путь: либо снять своё фото по образцу, либо запросить у производителя
(письма — в файле `ЗАПРОС-ФОТО-производителям`), либо купить на стоке.

## КОРОТКО: ПОРЯДОК ДЕЙСТВИЙ

1. **Своё фото склада** — самое сильное и бесплатное. Мешки, стеллажи, отгрузка.
2. **BORESTORE** — для всего бурового инструмента, фото каждой позиции.
3. **Сайты производителей** (XCMG, Normet, DigiTrak) — фото конкретных моделей.
   Как дилер, запросите официально (письма — в `ЗАПРОС-ФОТО-производителям`).
4. **Поиск на стоках** — для типовых позиций (трубы, ножи, муфты).

**Ссылки с `google.com/search?...&tbm=isch`** открывают поиск картинок Google
с готовым запросом — увидите десятки примеров сразу. Но для сайта берите фото
только с легальных источников (стоки, свои, от производителя), не из выдачи Google.
