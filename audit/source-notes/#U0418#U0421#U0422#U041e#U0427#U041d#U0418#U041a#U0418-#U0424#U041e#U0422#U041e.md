# Источники фотографий для сайта ANKO GLOBAL

Список проверенных ресурсов под каждую категорию каталога.
Разделён на два типа:

- **Бесплатные стоки** — можно скачивать и использовать на коммерческом сайте бесплатно.
- **Сайты производителей** — официальные фото продукции. Как дилер, вы можете
  запросить их напрямую (письма — в файле `ЗАПРОС-ФОТО-производителям.md`).

К каждой категории даны **готовые поисковые запросы на английском и русском**.
Английские работают лучше — большинство стоков заточены под них.

## ВАЖНО ПРО ЛИЦЕНЗИИ (прочитайте до скачивания)

| Ресурс | Лицензия | Можно на коммерческом сайте? |
|--------|----------|------------------------------|
| **Unsplash** | Unsplash License | ✅ Да, бесплатно, без указания автора |
| **Pexels** | Pexels License | ✅ Да, бесплатно, без указания автора |
| **Pixabay** | Pixabay License | ✅ Да, бесплатно, без указания автора |
| **iStock** | Платно (роялти-фри) | ✅ Да, после покупки |
| **Getty Images** | Платно | ✅ Да, после покупки |
| **Dreamstime** | Платно + есть бесплатный раздел | ✅ Да, по лицензии |

**Правило:** на бесплатных стоках (Unsplash, Pexels, Pixabay) проверяйте, что у фото
именно их лицензия — иногда попадаются вставки-реклама с платных. На платных
(iStock, Getty, Dreamstime) — покупаете лицензию, и всё чисто.

**Никогда не берите фото просто из Google Картинок или с сайтов конкурентов** —
это чужая собственность, за это на коммерческом сайте можно получить претензию.

## РЕКОМЕНДУЕМЫЙ ПОРЯДОК ДЕЙСТВИЙ

1. **Своё фото склада** — самое сильное. Мешки, стеллажи, отгрузка. Ни у кого нет.
2. **BORESTORE** — для бурового инструмента, лучший референс с фото каждой позиции.
3. **Медиа-киты производителей** — для установок, локаторов, химии Normet.
   Письма-запросы готовы в файле `ЗАПРОС-ФОТО-производителям.md`.
4. **Бесплатные стоки (Pexels, Unsplash, Pixabay)** — для общих кадров:
   буровая в работе, стройплощадка, трасса.
5. **Платные (iStock, Dreamstime)** — если нужно точное попадание (реамер, XCMG)
   и не жалко $10-15 за фото.

**Универсальный кадр для главной страницы:** буровая установка ГНБ в работе на
объекте. Запрос на стоках: `horizontal directional drilling rig site` /
`буровая установка гнб на объекте`.
