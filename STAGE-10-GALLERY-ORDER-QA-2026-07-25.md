# ANKO Global — проверка порядка изображений

Дата проверки: 25 июля 2026 года.

## Результат

- Сопоставлены 24 карточки ANKO Global с исходными карточками a-line.
- Проверены 72 ссылки на дополнительные изображения.
- Порядок во всех галереях совпадает с исходным HTML a-line: `item2 → item3 → item4`.
- Главное изображение ANKO Global сохранено первым.
- Несовпадений последовательности: 0.
- Отсутствующих файлов: 0.

## Защита от регрессий

В сборку добавлен скрипт `tools/verify_gallery_order.py`. Он извлекает исходный
архив a-line, читает фактический порядок миниатюр в карточках, сравнивает его с
`site/js/product-galleries.js` и проверяет существование каждого изображения.

Команда проверки:

```bash
python3 tools/verify_gallery_order.py /path/to/a-line.by-clean-content.zip
```
