## Публикация

1. Сделать резервную копию текущего сайта.
2. Загрузить только содержимое `site/` в `public_html`/`www`.
3. Использовать PHP 7.4+ и Apache с требуемыми модулями.
4. Настроить `LEAD_TO_EMAIL=main.accentline@gmail.com`, реальную доставку формы
   и проверить серверное отклонение заявки без согласия.
5. Выполнить staging-чеклист, Lighthouse и browser QA по публичному HTTPS URL.
6. Не загружать `audit/`, `docs/`, `source/` и `tools/` в web-root.
