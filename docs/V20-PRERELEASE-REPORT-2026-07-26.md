## 1. Результат

Подготовлена отдельная предрелизная сборка `v20`. Исходный ZIP `v19` не
изменялся и остаётся резервной копией.

Статическая регрессия завершена со статусом `passed`, без ошибок и
предупреждений. Это не заменяет проверку опубликованного сайта: HTTP-ответы,
реальную отправку формы, браузерный рендеринг, Lighthouse и Core Web Vitals
можно подтвердить только на публичном HTTPS-адресе.

Динамический рендеринг на семи ширинах не заявляется как выполненный:
окончательный browser QA входит в послепубликационную приёмку.

## 5. Формы и безопасность

Сохранены ранее добавленные:

- CSRF-токен;
- honeypot;
- серверная проверка согласия;
- проверка телефона;
- фиксация редакции политики и времени согласия;
- ограничение пяти попыток в час на IP;
- отсутствие токенов Telegram в браузере.

Добавлены:

- предел тела запроса 65 536 байт с ответом `413`;
- атомарная запись rate limit через `flock`;
- безопасный отказ `503`, если состояние ограничителя нельзя прочитать или
  сохранить;
- ограничение и очистка URL формы;
- двухэтапный CSP с уникальным nonce.

По умолчанию PHP отдаёт `Content-Security-Policy-Report-Only`. После проверки
публичного сайта переменная `CSP_ENFORCE=1` включает блокирующий
`Content-Security-Policy`. До этого момента CSP нельзя считать полностью
введённым в эксплуатацию.

## 7. Редакционный план без выдуманных данных

Следующие материалы не добавлялись в `v20`, потому что для них нужны
технические паспорта или проверка эксперта:

1. Сравнение полимеров по функции, грунту, минерализации воды и совместимости —
   только по актуальным TDS/SDS каждой позиции.
2. Руководство по выбору семейств Normet — по задаче, основанию и технологии,
   с привязкой к официальным техническим листам.
3. Словарь терминов ГНБ: PAC, PHPA, TDS, SDS, SDR, фильтрация, реология,
   крутящий момент, усилие протяжки.
4. Категорийные FAQ. Разметка `FAQPage` добавляется только к вопросам и
   ответам, которые полностью видимы пользователю.
5. Связки «задача → исходные данные → категория → консультация» для бентонитов,
   полимеров, установок и инструмента.

## 8. AI/GEO — решение владельца

Файл `robots.txt` намеренно не менялся. Сейчас явно разрешены:

- `OAI-SearchBot`;
- `GPTBot`;
- `PerplexityBot`;
- `ClaudeBot`;
- `Google-Extended`.

Отдельной группы `ChatGPT-User` нет. Это не статическая ошибка, а политика,
которую должен утвердить владелец.

OpenAI документирует независимое управление поисковым `OAI-SearchBot` и
обучающим `GPTBot`. Поэтому перед публикацией следует выбрать один из
вариантов:

- разрешить поиск и обучение;
- разрешить поиск, запретить обучение;
- задать более ограничительную собственную политику.

`llms.txt` сохранён как экспериментальный вспомогательный файл. Он не
рассматривается как обязательный стандарт или гарантия попадания в AI-ответы.

## 10. После публикации

Обязательные проверки на HTTPS:

1. `200`, `301`, `404`, `419`, `422`, `429`, `503`.
2. Редиректы HTTP → HTTPS, `www` → без `www`, `/index.php` → `/`.
3. HSTS, `X-Content-Type-Options`, `Referrer-Policy`,
   `Permissions-Policy`, CSP.
4. CSP сначала в report-only, затем с `CSP_ENFORCE=1`.
5. Успешная отправка всех трёх форм и фактическая доставка письма.
6. Отклонение формы без согласия, без CSRF и с превышением лимитов.
7. Браузерная проверка 320, 375, 390, 768, 1024, 1440 и 1920 px.
8. Chrome, Firefox, Safari и Edge; клавиатура и экранный диктор.
9. Lighthouse mobile/desktop, TTFB и полевые Core Web Vitals.
10. Доступ `robots.txt`, Sitemap, Googlebot, YandexBot, Bingbot и
    согласованных AI-краулеров.
11. Rich Results / Schema Validator и фактический HTML после PHP-рендеринга.
12. Индексация и отчёты Google Search Console, Яндекс Вебмастер и Bing
    Webmaster Tools.
