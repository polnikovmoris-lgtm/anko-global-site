# ANKO GLOBAL — Stage-06 Staging Validation Checklist

Дата: 24.07.2026

## Развёртывание

- [ ] Сделана резервная копия текущего сайта.
- [ ] В web-root загружено только содержимое папки `site/`.
- [ ] Используется PHP 7.4 или новее.
- [ ] Подтверждены Apache-модули `mod_rewrite`, `mod_headers`, `mod_expires`, `mod_deflate`; при наличии — `mod_brotli`.

## URL и сервер

- [ ] HTTP перенаправляется на HTTPS.
- [ ] `/index.php` перенаправляется на `/` с HTTP 301.
- [ ] Неизвестный URL возвращает кастомную страницу и HTTP 404.
- [ ] `send.php` не индексируется и GET-запрос возвращает 405.
- [ ] `robots.txt`, `sitemap.xml` и `llms.txt` открываются корректно.
- [ ] Проверены HSTS, CSP/прочие security headers, cache-control и сжатие.

## Формы

- [ ] Настроены `LEAD_TO_EMAIL` и `LEAD_FROM_EMAIL`.
- [ ] Настроен SMTP/транзакционный сервис либо проверена работа `mail()`.
- [ ] Выполнена реальная заявка с desktop.
- [ ] Выполнена реальная заявка с mobile.
- [ ] Проверено получение письма, тема, кодировка и данные заявки.
- [ ] Проверены SPF, DKIM и DMARC.
- [ ] При использовании Telegram заданы `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.

## Browser QA

- [ ] Chrome desktop и mobile.
- [ ] Safari desktop/iPhone.
- [ ] Edge desktop.
- [ ] Android Chrome.
- [ ] Проверены ширины 1440, 1024, 768, 430 и 360 px.
- [ ] Проверены мобильное меню, поиск, модальное окно, формы, звонки и внешние ссылки.
- [ ] Нет горизонтальной прокрутки и перекрытия контента системной клавиатурой.

## Производительность

- [ ] Lighthouse Mobile выполнен по публичному HTTPS URL.
- [ ] Lighthouse Desktop выполнен по публичному HTTPS URL.
- [ ] Проверены LCP, CLS, INP/TBT и размер переданных ресурсов.
- [ ] Проверены cache headers для CSS, JS, JPG, WebP, PNG и SVG.
- [ ] Подтверждено применение Brotli/Deflate.

## SEO и публикация

- [ ] Canonical соответствует production-домену.
- [ ] Open Graph-превью доступны поисковому роботу и соцсетям.
- [ ] Sitemap отправлен в панели вебмастеров.
- [ ] Проверены robots/noindex для служебных страниц.
- [ ] Аналитика и cookie consent включены только после утверждения политики.

## Решение о выпуске

- [ ] Все критические пункты закрыты.
- [ ] Выполнен backup/rollback test.
- [ ] Зафиксированы дата, версия и SHA-256 опубликованной сборки.
- [ ] Назначен ответственный за мониторинг заявок после запуска.
