## Дополнительные исправления

- Добавлены недостающие `BreadcrumbList` для десяти новых товаров.
- Добавлены ссылка пропуска навигации, единый `main-content` и более
  контрастные состояния фокуса.
- `llms.txt` превращён в краткое навигационное резюме и синхронизирован с
  каталогом. Файл по-прежнему обозначен как экспериментальный.
- Для BAULUX, Bentolux, CETCO, КЗБО и Universal HDD добавлены проверяемые
  сведения, официальные источники и дата проверки.
- Для FDP и WAMET неподтверждённые числа не публикуются: вместо них
  приведён перечень исходных данных для подбора и требование сверить
  паспорт конкретной модели.
- Обнаружен скрытый семантический дубль: `product-ultra-gel.php` ошибочно
  представлял CETCO ULTRA GEL как AnkoBent. В каталоге оставлена одна
  корректная карточка `product-cetco-ultragel.php`; прежний URL отвечает
  постоянным редиректом и сохранён как поисковый псевдоним.
- Обновлены версии CSS и JavaScript в URL ресурсов для сброса старого
  браузерного кеша.

## Незакрытые задачи

1. У 34 товарных карточек остаётся менее 180 видимых слов. Это
   диагностический порог, а не требование поисковых систем. Расширять
   страницы следует только после получения паспортов, TDS/SDS,
   совместимости и актуальной комплектации.
2. Для FDP и WAMET нужны подтверждённые производителем перечни моделей и
   паспортные характеристики.
3. Решение о правилах для поисковых и обучающих AI-краулеров должен принять
   владелец; `robots.txt` намеренно не менялся.
4. CSP следует сначала включить в режиме `Report-Only` на хостинге и
   проверить аналитику, формы и внешние сервисы.
5. 57 неиспользуемых изображений объёмом около 15,8 МБ не удалялись без
   отдельной проверки лицензий и необходимости хранения.
6. До включения аналитики требуется определить юридический режим согласия
   и технически блокировать необязательные скрипты, если это необходимо.

## Что обязательно проверить после публикации

- HTTPS, основной домен, фактические коды 301/404/500 и отсутствие цепочек;
- работу `.htaccess`, HSTS, кеширование, Brotli/Gzip и защитные заголовки;
- отправку формы, CSRF, отклонение заявки без согласия, почту и Telegram;
- 301 с `product-ultra-gel.php` и `product-igla-20tb.php`;
- страницу контактов и внешние ссылки маршрута;
- адаптивную вёрстку на 320, 375, 390, 768, 1024, 1440 и 1920 px;
- Lighthouse и Core Web Vitals для главной, категории и нескольких товаров;
- Rich Results, Schema Validator, Google Search Console, Яндекс Вебмастер и
  Bing Webmaster Tools;
- доступ поисковых и AI-ботов после решения владельца по `robots.txt`.

Серверные, визуальные и полевые скоростные проверки не выдаются за
выполненные: для них необходим опубликованный HTTPS URL.
