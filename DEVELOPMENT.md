# Разработка ANKO Global

## Быстрый старт

Требования:

- PHP 7.4 или новее;
- Python 3.10 или новее и Pillow;
- Node.js 18 или новее;
- GNU Make.

Установка Python-зависимости:

```bash
python3 -m pip install Pillow
```

Полная проверка:

```bash
make check
```

Локальный предпросмотр:

```bash
make serve
```

После запуска сайт доступен по адресу `http://127.0.0.1:8080`.

## Рабочий процесс

1. Создать ветку `agent/<задача>` от актуальной `main`.
2. Внести изменение и синхронизировать `source/` с `site/`, если затронуты
   исходные CSS или JavaScript.
3. Запустить `make check`.
4. Проверить изменённые страницы в браузере на телефоне и компьютере.
5. Обновить `docs/CHANGELOG.md`.
6. Создать draft pull request и показать результат владельцу.
7. Слить изменение только после подтверждения.
8. Публиковать на хостинг отдельным действием и только после отдельного
   подтверждения.

На сервер загружается только содержимое `site/`. Подробный порядок публикации
описан в `docs/DEPLOY.md`.
