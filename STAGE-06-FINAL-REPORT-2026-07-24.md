## 2. Исправления мобильного UX и доступности

### Мобильная навигация

- Кнопка меню связана с панелью через `aria-controls`.
- Состояния меню синхронизированы через `aria-expanded` и `aria-hidden`.
- Меню закрывается по `Escape` с возвратом фокуса на кнопку.
- Меню автоматически закрывается при переходе к desktop-ширине.
- При открытом меню блокируется прокрутка фоновой страницы.

### Поиск

- Поле поиска оформлено как ARIA combobox.
- Результаты поиска оформлены как listbox/options.
- Активный результат передаётся через `aria-activedescendant`.
- Состояния `aria-expanded` и `aria-selected` обновляются при навигации с клавиатуры.
- Поиск закрывается по `Escape` без потери доступности.

### Модальное окно заявки

- При открытии фокус переводится в поле телефона.
- Реализована циклическая навигация Tab/Shift+Tab внутри окна.
- Окно закрывается по `Escape`.
- После закрытия фокус возвращается на элемент, открывший окно.
- Кнопка закрытия увеличена до 44×44 px.

### Формы и адаптивность

- Исправлено горизонтальное переполнение узкой страницы политики.
- Добавлен безопасный перенос длинных строк и ссылок.
- Восстановлены видимые состояния `:focus-visible` для полей, поиска, кнопок и ссылок.
- Honeypot скрыт способом, не создающим горизонтальный выход за viewport.
- Основные мобильные элементы управления имеют высоту не менее 44 px.
- Добавлена поддержка `prefers-reduced-motion`.
